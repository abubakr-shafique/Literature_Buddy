# Changelog

## 0.1.0
* PDF viewer with highlights (checkable as chat context), search, zoom, drag & drop, URL loading.
* Parser: sections, figures (raster + vector), tables, equations, references, captions.
* Hybrid retrieval (dense + BM25 + RRF, optional rerank) with text↔figure linking.
* Ollama, OpenAI-compatible, Transformers (LLM + VLM) and llama.cpp backends; hardware profiles 16 GB / 24 GB / lite.
* Cited answers with citation validation and quote verification; persistent chat and highlights.
